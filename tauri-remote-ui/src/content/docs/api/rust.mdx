Reference for the public surface of the `tauri-remote-ui` crate. Bring the
extension traits into scope to call their methods:

```rust
use tauri_remote_ui::{EmitterExt, OriginType, RemoteUiConfig, RemoteUiExt};
```

## `init`

```rust
pub fn init() -> tauri::plugin::TauriPlugin<tauri::Wry>
```

Creates the plugin. Register it on your builder:

```rust
tauri::Builder::default()
    .plugin(tauri_remote_ui::init())
    // ...
```

## `RemoteUiExt`

Extension trait implemented for `tauri::AppHandle` that manages the server
lifecycle. All methods are `async`.

<table>
  <thead>
    <tr>
      <th>Method</th>
      <th>Returns</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>start_remote_ui(config: RemoteUiConfig)</code></td>
      <td><code>Result&lt;(), tauri::Error&gt;</code></td>
      <td>Starts the server. Errors if already running.</td>
    </tr>
    <tr>
      <td><code>stop_remote_ui()</code></td>
      <td><code>Result&lt;(), tauri::Error&gt;</code></td>
      <td>Stops the server if running and reloads the window.</td>
    </tr>
    <tr>
      <td><code>is_remote_ui_running()</code></td>
      <td><code>bool</code></td>
      <td>Whether the server is currently active.</td>
    </tr>
    <tr>
      <td><code>remote_ui_port()</code></td>
      <td><code>Option&lt;u16&gt;</code></td>
      <td>The bound port, or <code>None</code> if not running.</td>
    </tr>
  </tbody>
</table>

```rust
app.start_remote_ui(RemoteUiConfig::default().set_port(Some(9090))).await?;
let port = app.remote_ui_port().await; // Some(9090)
let running = app.is_remote_ui_running().await; // true
app.stop_remote_ui().await?;
```

<Aside type="tip">
Use `remote_ui_port()` when you start with `set_port(None)` and need to surface
the OS-chosen port to the user or a test harness.
</Aside>

## `EmitterExt`

Extension trait implemented for `tauri::WebviewWindow<R>`. Use it to emit events
that reach both the native window and any connected remote client.

<table>
  <thead>
    <tr>
      <th>Method</th>
      <th>Notes</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>emit(event, payload)</code> <em>(async)</em></td>
      <td>Emits over WebSocket (if remote active) <strong>and</strong> via Tauri's event system.</td>
    </tr>
    <tr>
      <td><code>emit_to(target, event, payload)</code></td>
      <td>Standard targeted emit.</td>
    </tr>
    <tr>
      <td><code>emit_str(event, payload)</code></td>
      <td>Emit with a <code>String</code> payload.</td>
    </tr>
    <tr>
      <td><code>emit_str_to(target, event, payload)</code></td>
      <td>Targeted string emit.</td>
    </tr>
    <tr>
      <td><code>emit_filter(event, payload, filter)</code></td>
      <td>Emit to targets passing a filter.</td>
    </tr>
    <tr>
      <td><code>emit_str_filter(event, payload, filter)</code></td>
      <td>String payload variant of <code>emit_filter</code>.</td>
    </tr>
  </tbody>
</table>

```rust
use tauri::Manager;
use tauri_remote_ui::EmitterExt;

let window = app.get_webview_window("main").unwrap();
window.emit("counter", serde_json::json!({ "result": 42 })).await?;
```

<Aside type="caution">
Only the async `emit` forwards to remote clients. The synchronous helpers
(`emit_to`, `emit_str`, …) delegate to Tauri's standard emitter and reach the
native window only.
</Aside>

## `RemoteUiConfig`

Builder for server configuration. See [Configuration](/tauri-remote-ui/configuration/)
for full details. Summary:

- `set_port(Option<u16>)`, `set_allowed_origin(OriginType)`,
  `set_bundle_path(Option<String>)`, `set_primary_window_label(impl Into<String>)`
- `enable_application_ui()`, `minimize_app()`, `disable_info_url()`
- `set_custom_blocking_ui(Option<String>)`, `set_custom_disconnect_ui(Option<String>)`
- getters: `allowed_origin()`, `port()`, `bundle_path()`, `primary_window_label()`

## `OriginType`

Network access scope. See [Security](/tauri-remote-ui/security/).

```rust
pub enum OriginType { Localhost, Subnet, Any }
```

- `Localhost` — binds `127.0.0.1`; local machine only (default).
- `Subnet` — binds `0.0.0.0`; same-subnet peers + loopback.
- `Any` — binds `0.0.0.0`; no peer filtering.

`OriginType::bind_address()` returns the bind address string for the scope.

## `Error`

The crate's error type (`tauri_remote_ui::Error`, with
`tauri_remote_ui::Result<T>`):

<table>
  <thead>
    <tr>
      <th>Variant</th>
      <th>When</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>Io</code></td>
      <td>Wrapped <code>std::io::Error</code>.</td>
    </tr>
    <tr>
      <td><code>Tauri</code></td>
      <td>Wrapped <code>tauri::Error</code>.</td>
    </tr>
    <tr>
      <td><code>Json</code></td>
      <td>Wrapped <code>serde_json::Error</code>.</td>
    </tr>
    <tr>
      <td><code>Http</code></td>
      <td>Wrapped <code>hyper::http::Error</code>.</td>
    </tr>
    <tr>
      <td><code>ServerAlreadyRunning</code></td>
      <td><code>start_remote_ui</code> called while already running.</td>
    </tr>
    <tr>
      <td><code>PrimaryWindowNotFound</code></td>
      <td>Configured primary window label does not exist.</td>
    </tr>
    <tr>
      <td><code>InvalidFrontendDist</code></td>
      <td><code>frontendDist</code> is a remote URL; a local path is required.</td>
    </tr>
    <tr>
      <td><code>WebSocket</code></td>
      <td>WebSocket transport error.</td>
    </tr>
    <tr>
      <td><code>Plugin</code></td>
      <td>Generic plugin error with context.</td>
    </tr>
  </tbody>
</table>

`Error` converts into `tauri::Error`, so it can be returned from the extension
trait methods that mirror Tauri's signatures.
