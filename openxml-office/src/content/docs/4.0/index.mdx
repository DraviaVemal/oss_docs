<section>
	<h2>What's new in v4.x</h2>
	<div class="oss-grid">
		<article class="oss-card">
			<h3>Rust core</h3>
			<p>
				A single Rust engine replaces the .NET-based v2.x/v3.x core, with
				no <code>unsafe</code> code in the public path.
			</p>
		</article>
		<article class="oss-card">
			<h3>Cross-language bindings</h3>
			<p>
				Stage 1 ships native packages for .NET and Python through a Rust
				FFI layer. Go, TypeScript and Java land in Stage 2.
			</p>
		</article>
		<article class="oss-card">
			<h3>Consistent behaviour</h3>
			<p>
				Because every language calls the same Rust core, output stays
				identical across .NET, Python and friends.
			</p>
		</article>
		<article class="oss-card">
			<h3>Office 2007+ compatible</h3>
			<p>
				The output targets Microsoft Office 2007 and newer, broadening
				compatibility versus the earlier release lines.
			</p>
		</article>
	</div>
</section>
