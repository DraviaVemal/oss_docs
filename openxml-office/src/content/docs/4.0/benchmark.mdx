Spreadsheet write benchmark of openxml-office v4.x against a comparison library for each language.

## How to read this benchmark

The charts compare v4.x with the other library at the same number of cells. A ratio of `1.00×` means they are equal; above `1.00×` is a v4.x gain, and below `1.00×` is a v4.x loss. Green marks a gain and red marks a loss. Speed and allocation are shown separately because a library can be faster while allocating more memory, or vice versa. The exact ratios are printed beside each bar.

<TabItem label='C#'>

- Generated: 2026-10-20 01:33:09Z
- Machine: Common (8 logical CPUs)
- Runtime: 10.0.12 on Ubuntu 26.04.1 LTS
- Layout: cells written in rows of up to 100 columns.

Notes:
- **Alloc** = total managed bytes allocated during the run (churn), **Managed Δ** = managed heap retained afterwards.
- **WS** = OS working set, **Priv** = private memory. CPU % is normalised across all logical processors (100% = one fully busy core-equivalent).
- **µs/cell** = wall time per cell, **Cells/s** = throughput.
