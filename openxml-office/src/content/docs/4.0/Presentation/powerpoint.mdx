The `PowerPoint` class/struct is the entry point for creating and opening PowerPoint (`.pptx`) presentations. In the current alpha the presentation engine supports creating a new blank presentation, opening an existing presentation and saving it back out. Slide-level authoring is in active development.

### Methods

<table><thead><tr><th width="260">Rust</th><th width="240">C#</th><th>Function</th></tr></thead><tbody>
<tr><td><code>PowerPoint::new(path, props)</code></td><td><code>new PowerPoint(props)</code> / <code>new PowerPoint(path, props)</code></td><td>Create a new presentation or open an existing file</td></tr>
<tr><td><code>save_as(path)</code></td><td><code>SaveAs(path)</code></td><td>Save the presentation to a file</td></tr>
</tbody></table>

### Basic Code Samples

<Tabs syncKey='language'>
<TabItem label='Rust'>
```rust
use draviavemal_openxml_office::presentation_2007::{PowerPoint, PowerPointPropertiesModel};

// Create a new blank presentation (pass Some(path) to open an existing file)
let file = PowerPoint::new(None, PowerPointPropertiesModel::default())
    .expect("Create New File Failed");
file.save_as("./output.pptx").expect("Failed to save presentation");
```
</TabItem>
<TabItem label='C#'>
```csharp
using draviavemal.openxml_office.presentation_2007;

// Create a new blank presentation
PowerPoint powerPoint = new(new()
{
    IsInMemory = false
});
powerPoint.SaveAs("./output.pptx");

// Open an existing presentation
PowerPoint existing = new("basic_test.pptx", new()
{
    IsInMemory = false
});
existing.SaveAs("./edited.pptx");
```
</TabItem>
