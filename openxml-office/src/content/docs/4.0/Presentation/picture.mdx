### `PictureSetting` Options

| Property            | Type                                                                        | Details                     |
| ------------------- | --------------------------------------------------------------------------- | --------------------------- |
| hyperlinkProperties | [HyperlinkProperties](../spreadsheet/shared.md#hyperlinkproperties-setting) | Hyperlink properties setting|
| imageType           | ImageType                                                                   | Inserted Image Type         |
| height              | uint                                                                        | Image Height                |
| width               | uint                                                                        | Image Width                 |
| x                   | uint                                                                        | Image Top Left X            |
| y                   | uint                                                                        | Image Top Left Y            |
