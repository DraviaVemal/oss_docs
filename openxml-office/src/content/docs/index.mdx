<section>
	<h2>Why openxml-office</h2>
	<div class="oss-grid">
		<article class="oss-card">
			<h3>One Rust core</h3>
			<p>
				A single, well-tested engine does the heavy lifting, so behaviour
				stays consistent no matter which language you call it from.
			</p>
		</article>
		<article class="oss-card">
			<h3>Multi-language bindings</h3>
			<p>
				Native packages for .NET, Go, Node.js and Python ship through each
				ecosystem's own package manager — no extra runtime dependencies.
			</p>
		</article>
		<article class="oss-card">
			<h3>Developer-first API</h3>
			<p>
				Intuitive namespaces and helpers, designed for IDE auto-completion
				and an efficient, in-process workflow.
			</p>
		</article>
		<article class="oss-card">
			<h3>Office-compatible output</h3>
			<p>
				Targets Microsoft Office 2013 and newer, producing files that open
				cleanly in the apps your users already have.
			</p>
		</article>
	</div>
</section>
