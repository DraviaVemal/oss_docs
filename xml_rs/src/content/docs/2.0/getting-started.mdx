## Requirements

- Rust (2021 edition)
- UTF-8 encoded XML input

## Install

<Steps>

1. Add the crate to your project:

   ```shell
   cargo add draviavemal-xml_rs
   ```

2. Import the types you need:

   ```rust
   use draviavemal_xml_rs::{
       XmlDeserializer, XmlSerializer, XmlDocument, XmlAttribute, XmlElementContentType,
   };
   ```

</Steps>

## Parse, read and serialize

The three building blocks are
[`XmlDeserializer`](/xml_rs/2.0/api-reference/#xmldeserializer) (XML → DOM),
[`XmlDocument`](/xml_rs/2.0/api-reference/#xmldocument) (the tree) and
[`XmlSerializer`](/xml_rs/2.0/api-reference/#xmlserializer) (DOM → XML).

```rust
use draviavemal_xml_rs::{XmlDeserializer, XmlSerializer};

fn main() -> anyhow::Result<()> {
    let xml = r#"<catalog xmlns:t="http://example.org/test">
        <book id="bk101"><title>XML Basics</title></book>
    </catalog>"#;

    // Parse bytes into a document tree.
    let document = XmlDeserializer::vec_to_xml_doc_tree(xml.as_bytes().to_vec())?;

    // Read the root element.
    let root_id = document.get_root_id();
    let root = document.get_element(root_id)?;
    println!("root tag: {}", root.get_tag()); // "catalog"

    // Serialize back to XML bytes (round-trip safe).
    let bytes = XmlSerializer::xml_tree_to_vec(&document)?;
    println!("{}", String::from_utf8_lossy(&bytes));
    Ok(())
}
```

Serialization borrows the document immutably (`&XmlDocument`), so you can keep
reading from the tree afterwards.

<Aside type="note">
Fallible operations return `anyhow::Result`. Use `?` in a function returning
`anyhow::Result<()>`, or handle the `Err` explicitly.
</Aside>

## Read from / write to files

```rust
use draviavemal_xml_rs::{XmlDeserializer, XmlSerializer};

let document = XmlDeserializer::file_to_xml_doc_tree("input.xml")?;
XmlSerializer::xml_doc_tree_to_file(&document, "output.xml")?;
```

<Aside type="tip">
Need compacter namespaces on output? Pass a
[`SerializeOptions`](/xml_rs/2.0/api-reference/#serializeoptions) with
`optimize_namespaces: true` to `xml_tree_to_vec_with` /
`xml_doc_tree_to_file_with` to hoist prefixed declarations to their lowest
common ancestor and drop unused ones.
</Aside>
