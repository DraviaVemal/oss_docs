A guided tour of the public surface. For the always-current, fully generated
reference see [docs.rs/draviavemal-xml_rs](https://docs.rs/draviavemal-xml_rs).

```rust
use draviavemal_xml_rs::{
    XmlDeserializer, XmlSerializer, SerializeOptions,
    XmlDocument, XmlElement, XmlAttribute,
    XmlElementContentType, NamespaceDeclaration,
};
```

<Aside type="note">
Nearly every method comes in two flavours: a **raw** variant that takes a
`prefix:name` string verbatim, and a namespace-aware `*_ns` variant that takes a
[`NamespaceDeclaration`](#namespacedeclaration) and resolves the alias against
the live document scope. Prefer the `_ns` variants for round-trip-safe
namespaces.
</Aside>

## `XmlDeserializer`

## `NamespaceDeclaration`

A `Copy` value pairing a namespace URI with its canonical alias, passed to every
`*_ns` API. Resolution precedence is `alias_override` &gt; the alias already in
scope for the URI &gt; `default_alias`.

<table>
  <thead>
    <tr>
      <th>Member</th>
      <th>Purpose</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>uri: &amp;'static str</code></td>
      <td>The W3C namespace URI.</td>
    </tr>
    <tr>
      <td><code>default_alias: &amp;'static str</code></td>
      <td>Alias used when the URI is not already declared in scope.</td>
    </tr>
    <tr>
      <td><code>alias_override: Option&lt;&amp;'static str&gt;</code></td>
      <td>Forces this alias regardless of any alias already bound to the URI.</td>
    </tr>
    <tr>
      <td><code>new(uri, default_alias)</code></td>
      <td><code>const</code> constructor with no override.</td>
    </tr>
    <tr>
      <td><code>with_override(uri, default_alias, alias_override)</code></td>
      <td><code>const</code> constructor that forces a specific prefix.</td>
    </tr>
  </tbody>
</table>

```rust
const MAIN_NS: NamespaceDeclaration = NamespaceDeclaration::new(
    "http://schemas.openxmlformats.org/spreadsheetml/2006/main",
    "main",
);
```
