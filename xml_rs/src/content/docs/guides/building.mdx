You can build a document programmatically and serialize it, or edit a parsed
tree in place. Mutating methods end in `_mut` and most return the new node's
[`NodeId`](/xml_rs/api-reference/#types).

## Create a document and root

```rust
use draviavemal_xml_rs::{XmlDocument, XmlAttribute};

let mut document = XmlDocument::new();

let root_id = document.create_root_element_mut(
    "root",
    Some(vec![XmlAttribute::new("version".into(), "1.0".into())]),
)?;
```

## Append children

```rust
let child_id = document.append_child_element_mut(
    root_id,
    "child",
    Some(vec![XmlAttribute::new("id".into(), "child1".into())]),
)?;
```

## Add text, comments and attributes

```rust
let element = document.get_element_mut(child_id)?;
element.add_text_mut("Hello World")?;
element.add_comments_mut("a note")?;
element.add_attribute_mut(XmlAttribute::new("lang".into(), "en".into()))?;

// Add-or-replace instead of erroring on a duplicate name
element.add_replace_attribute_mut(XmlAttribute::new("lang".into(), "fr".into()))?;

// Set the initial attribute list (only when the element has none yet)
element.set_attribute_mut(vec![XmlAttribute::new("id".into(), "c1".into())])?;

// Remove attributes
element.remove_attribute_mut("lang");        // by local name
element.remove_attribute_ns_mut("t:lang");   // by namespaced name
element.clear_attribute_mut()?;              // remove all (returns the count)
```

## Remove elements and clear content

Operate on the document to remove nodes or empty an element:

```rust
// Remove all children of an element but keep the element itself
document.clear_element_content_mut(child_id)?;

// Remove an element and its entire subtree
document.remove_element_mut(child_id)?;
```

## Serialize

```rust
use draviavemal_xml_rs::XmlSerializer;

let bytes = XmlSerializer::xml_tree_to_vec(&mut document)?;
// or write straight to disk
XmlSerializer::xml_doc_tree_to_file(&mut document, "out.xml")?;
```

<Aside type="note">
Serialization is **round-trip safe**: original namespace prefixes and attribute
order are preserved, and comments are re-emitted. Text content is XML-escaped
automatically.
</Aside>
