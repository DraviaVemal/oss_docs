<section>
	<h2>Features</h2>
	<div class="oss-grid">
		<article class="oss-card">
			<h3>Namespace-aware</h3>
			<p>
				Full namespace resolution with a prefix → URI stack and correct
				QName parsing.
			</p>
		</article>
		<article class="oss-card">
			<h3>Round-trip safe</h3>
			<p>
				Serialization preserves original namespace prefixes and attribute
				order, so parse → serialize stays faithful.
			</p>
		</article>
		<article class="oss-card">
			<h3>Low memory</h3>
			<p>
				An ID-based tree model (arena-like) keeps allocations flat for large
				documents — with no <code>unsafe</code> code.
			</p>
		</article>
		<article class="oss-card">
			<h3>Order-preserving attributes</h3>
			<p>
				Attributes keep their source order via an index map, important for
				deterministic output.
			</p>
		</article>
		<article class="oss-card">
			<h3>Comments &amp; mixed content</h3>
			<p>
				Elements, text, mixed content and comments are all preserved in the
				DOM.
			</p>
		</article>
		<article class="oss-card">
			<h3>UTF-8 focused</h3>
			<p>
				Reads the XML declaration (version, encoding, standalone) and
				normalizes line breaks.
			</p>
		</article>
	</div>
</section>
